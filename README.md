One single line of text — the phone battery's last text message to the charger it waited for all day.

> 1%. waited all day by the outlet and you charged the tablet first. THE TABLET. it plays candy crush. i die as i lived: petty.

A battery with a small voice, a grudge, and no shame about dying petty: it waited all day by the outlet, watched the charger pick the tablet, and spends its final percent on a jealous last word. Not a sad goodbye — a complaint, filed at 1%.

## Run it

```sh
python3 main.py
```

Writes exactly one line (125 characters) to `/output/entry.txt`.
